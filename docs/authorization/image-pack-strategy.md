# 阿里图包渠道 — 拿图策略与风险转移

> 背景：已通过阿里国际站联系 CRONY，对方明确"用图片做跨境贸易允许，会提供图包"。
> **这一条比我原先担心的健康得多**：平台生态本就是"供应商供货与图、贸易商拿图去卖"，
> 对方主动给图包 = 明确知情同意，侵权风险基本清零。
>
> 但风险没有消失，而是**换了个位置** —— 从"能不能用"变成"用了之后有没有优势"。

---

## 一、拿图包时，顺口确认这 4 件事（一句话的事，但决定了后面所有自由度）

在阿里聊天里发出去，对方回一句就够，**聊天记录截图即留档**：

> 图包收到了，谢谢！确认几个用法，免得以后用错：
> 1. 图包除了平台店铺，**可以用在我们的独立站和海外推广**（开发信、LinkedIn、Google Ads）吗？
> 2. 图上的 logo / 水印，我们是**保留你们的，还是可以换成我们自己的品牌**？
> 3. 有没有**不在图包范围内、不能外发**的图（比如车间全景、客户合影）？
> 4. 可否额外发一批**没上传过官网/阿里的原图**？我们优先用这批，避免和别的分销商撞图。

第 4 条是关键，理由见下。

---

## 二、风险转移：从"侵权"变成"同质化"

| 风险 | 之前（怕什么） | 现在（该怕什么） |
|---|---|---|
| 侵权被追责 | ❌ 已基本清零（对方知情给图） | — |
| **重复内容** | — | ⚠️ **主风险**：图包大概率同时发给多个分销商，几十个站用同一套图 |
| **同质化竞争** | — | ⚠️ 客户搜同款图比价，我们和别的分销商站在同一起跑线 |
| 身份不一致 | — | 🟡 OEM 工厂站上放成品分销图，客户可能误判我们就是生产方 |

**Google 不会因为图片重复直接惩罚**，但会稀释：
- 图片搜索里撞图 → 流量被几十个站分走
- 客户看到一模一样的图 → 觉得我们是二道贩子，转化率掉

---

## 三、破解办法：向工厂要"未公开原图"

这是本文件最值钱的一条建议。

| | 官网/阿里在架图 | 工厂未公开原图 |
|---|---|---|
| 版权 | 干净 | 同样干净（工厂给的） |
| 网上能否搜到 | 能，撞图风险高 | **搜不到，撞图风险≈0** |
| 画质 | 平台压缩过 | 原图，更清晰 |
| 拿到难度 | 自己下载 | 多问一句即可 |

**做法**：第 4 条确认里直接要"没上架的图"。工厂通常有，只是没人问。

## 四、图片差异化三层策略（按投入递增）

### L0 — 全用图包（0 成本，当前默认）
能用，但没有辨识度。**仅适合上线抢时间，不建议长期停留。**

### L1 — 图包 + 自拍核心位（推荐，成本约 4–8 张自拍）
每个类目页只换掉最关键的几张，性价比最高：

| 位置 | 为什么换成自拍 |
|---|---|
| **类目页 hero 头图** | 第一眼 + Google 图片点击率，最值得投入 |
| **手持比例参照图** | 场景图里最容易被忽略，但最能建立"真实库存"信任 |
| **1–2 张细节特写** | 导环缠绕 / 轮座 / 碳布纹路，采购最想看的角度，图包往往没有 |

4 个类目页 × 2 张 = 8 张自拍，一次拍摄搞定。

### L2 — L1 + 统一后期（成本最低的差异化）
对图包的图做轻度处理，让它们"看起来是我们的"：
- 统一白底（去掉原图杂乱背景）
- 统一色温与裁切比例
- 加品牌角标（**不要**盖住产品本体）

⚠️ 不要做镜像翻转、拉伸变形这类处理 —— 鱼竿形状有辨识度，翻转一眼假。

## 五、文案侧同样要防重复（比图片更重要）

参数表我们已经是**从工厂参数表真实转录**，这点没问题。但要注意：

- **不要照抄阿里详情页的英文描述** —— 那是 CRONY 的文案，全网的同款分销商都在用
- 类目页的场景说明、定制选项、FAQ **必须自己写**（当前已是原创，保持）
- 参数表的**表述方式**可以重组：同是 2.13m，可以写 `7'0" (2.13 m)`，也可以写 `213 cm` —— 数据一样，文本指纹不同

**Google 判重复看文本不看图片**，所以文案原创 > 图片原创。

## 六、拿到图包后的执行流程

```bash
# 1. 图包放到 source/_raw/crony_pack/
# 2. 改 scripts/build_product_images.py 里的映射表，指向新文件
# 3. 重跑（幂等，改完重跑即可，不会破坏已有结构）
python scripts/build_product_images.py   # 转 WebP 1200px q82
python scripts/sitegen.py                # 重新生成页面
python scripts/smoke_test.py             # 261 项校验
```

替换后务必更新两处记录：
- `PENDING-BEFORE-PUBLISH.md` §2 图片来源清单（来源从"官网抓取"改为"阿里图包"）
- `scripts/product_images_manifest.json`（`source_page` 字段）
